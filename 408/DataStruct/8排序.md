## 1. 常规排序

### 1.1 插入排序

尝试将 a[i] 插入到 已经排好序的 [0, i-1] 中，不断交换直到遇比a[i]更小的

### 1.2 选择排序

每次选择当前最小值放在 a[i]

### 1.3 冒泡排序

每次选择当前最大值放在 a[n - i]

### 1.4 快速排序

```c
void quick_sort(int *q, int l, int r){
    if (l >= r) return;

    int i = l - 1, j = r + 1, x = q[(l + r) >> 1];
    
    while (i < j){
        do i ++ ; while (q[i] < x);
        do j -- ; while (q[j] > x);
        if (i < j) swap(&q[i], &q[j]);
    }

    quick_sort(q, l, j);
    quick_sort(q, j + 1, r);
}
```
