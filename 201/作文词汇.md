## 5. 图表/数据描述核心词汇

### 5.1. 趋势动词 + 副词搭配

| 趋势     | 动词                                                         | 副词-幅度大 | 副词-幅度小/平稳 |
| :------- | :----------------------------------------------------------- | :---------- | :--------------- |
| **上升** | increase / rise / grow                                       |             |                  |
| **下降** | decrease / reduce / decline / diminish / shrink / drop / fall |             |                  |
| **持平** | be flat / stand at / stay at / stabilize                     | —           | —                |
| **波动** | vary / fluctuate / rise and fall / undulate                  |             |                  |

>   **记忆口诀：** 升用 rocket/soar/surge，降用 plummet/slump，平用 stabilize，波动用 fluctuate。大幅加 sharply/dramatically，小幅加 gradually/steadily。

幅度大：

suddenly / notably / significantly

幅度小：

slightly / smoothly / gently

### 5.2. 占比/峰值/时间状语

| 功能         | 标准表达                                                     |
| :----------- | :----------------------------------------------------------- |
| **占比**     | **account for** 60% / **make up** 60% / the proportion of A **is** 60 percent |
| **峰值**     | **reach a peak** / **hit a high** (of...)                    |
| **时间跨度** | **between** A **and** B / **from** A **to** B / **during the period from** A **to** B / **throughout the past** XX years |
